02 / Architecture

The runtime stays small. The edges do the work.

Adapters translate physical or simulated systems into the same world model. An optional governance path can sit around action execution when a deployment needs authorization and hard control-plane guarantees.

active pathLive Go2 world
Go2 sensors→standard robot port→robot-world adapter→World Runtime→operator panel
optional pathGovernance
Mission API→Mission Server→signed Authorization→Supervisor Kernel→Driver

Event Log is the cross-cutting record. Scene, Attention, Replay, and Reports are projections over it. The governance packages are retained as an optional extension; the World Runtime does not depend on them.

03 / Current state

The loop works. Perception comes next.

The first World Runtime slice is implemented and connected to the live Go2 operator surface. The next step is turning sensor evidence into semantic entities and relationships, then binding physical action packs to the same actions used in simulation.
